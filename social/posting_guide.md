# Один MP4 — три сети

Один и тот же файл (1080×1920, H.264 + AAC, 13–16 с) подходит везде без изменений. Весь текст стоит в безопасной зоне: верхние ~180 px, нижние ~360 px и правые ~120 px свободны.

| | TikTok | Instagram Reels | YouTube Shorts |
|---|---|---|---|
| Загрузка | Приложение → + → «Загрузить» → MP4 | Приложение → + → Reel → MP4 | Приложение → + → Short → MP4 (≤ 3 мин, 9:16) |
| Обложка | «Изменить обложку» → «Загрузить» `_cover.png` (или кадр **до 0:07**) | «Изменить обложку» → «Добавить из галереи» → `_cover.png`. В сетке профиля режется до 3:4, центр сохраняется | В приложении можно только выбрать кадр: берите кадр **до отсчёта**. Свою миниатюру через YouTube Studio дают не всем аккаунтам |
| Подпись | Текст из captions.md, хэштеги в конце | Тот же текст; хэштеги можно перенести в первый комментарий | **Название** = `Guess the Madeira trail #1 (PR 6 …) #shorts`, описание = подпись |
| Ссылки | В подписи не кликаются → **ссылка в шапке** (`utm_source=tiktok`, campaign под тему недели) | В подписи не кликаются → ссылка в шапке (`utm_source=instagram`) | В описании Shorts ссылки тоже не кликаются. Используйте «Похожее видео» (если есть длинное видео) и ссылку в профиле канала (`utm_source=youtube`) |
| Звук | Наши «бипы» тихие. Можно добавить трендовый звук на 10–20 % громкости, но так, чтобы отсчёт был слышен | Так же. Музыку лучше добавлять внутри Instagram: за чужую музыку охват могут урезать | Музыку только из библиотеки Shorts (иначе сработает Content ID) |
| Водяные знаки | — | **Не заливайте** видео, скачанное из TikTok с его водяным знаком: Reels такие прячет. Только исходный MP4 | То же: только исходный MP4 |
| Ритм | 1 ролик в день: 2–3 левады в неделю + 1–2 PapaGaio | Те же ролики через 0–24 ч | Те же ролики; соберите плейлист «Guess the Levada» |

После публикации:
- В первый час отвечайте на первые комментарии, особенно на догадки («Close! It's on the same plateau 👀»).
- Комментарий с ответом закрепляйте **через сутки**, а не сразу: до этого догадки в комментариях работают на охват.
- Через 48 ч посмотрите статистику: какой % досмотрел до ответа на 0:10 и сколько переходов по ссылке в шапке (UTM в аналитике).
